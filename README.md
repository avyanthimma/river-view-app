🌊 River Watch
River Watch is a lightweight, mobile-first web application for community water-quality monitoring and environmental incident reporting along the Hillsborough River corridor. It empowers local residents to log field data (such as pH, turbidity, and dissolved oxygen) and submit geotagged reports on pollution or river hazards.


🛠️ Tech Stack & Dependencies
Frontend: Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
Styling & Fonts: Custom CSS variables, CSS Grid/Flexbox, Google Fonts (DM Sans & Fraunces).
Mapping: Leaflet.js (v1.9.4) for interactive map overlays and custom markers.
Backend / Database: Supabase JS Client (v2.49.1) for persistent real-time storage and anonymous upvoting.


✨ Features
Interactive Map: View official USGS/EPC monitoring stations alongside real-time user-reported hazards.
Community Incident Reports: Submit geotagged reports with category tags (e.g., trash, algae blooms, oil spills) and images.
Field Sensor Logging: Log custom water parameter readings (pH, turbidity, water temperature, dissolved oxygen).
Upvoting & Tracking: Track community concerns and local status updates using device-level identification without requiring login flows.
Educational Hub: In-app articles breaking down water quality metrics (e.g., NTU readings, pH thresholds, dissolved oxygen levels).
